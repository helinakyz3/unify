# UniFy

A small web app for university students to find people who are free at the same time, in the same place, and want to do the same thing.

## What it does

- **Match** — find one student who is free right now, in the same place, for the same activity
- **Pulse** — see what activities are happening near you right now
- **Groups** — join a small group (2-4 people) doing the same thing
- **Chat** — a simple chat after you connect with someone
- **Safety** — check-in timer, report and block, always a public campus location

No real photos, no GPS, no backend — everything runs locally for the demo.

## Running it

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Tests

npm test
